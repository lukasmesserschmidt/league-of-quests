# League of Quests

## Description

League of Quests is a tool for the game **League of Legends** that enhances gameplay by assigning tasks and challenges. Players receive quests and corresponding restrictions, which can be resolved by completing the assigned tasks.

## Features

- **Quest Assignment:** Provides players with specific tasks to complete during gameplay.
- **Restrictions:** Imposes various restrictions that can be removed upon task completion.
- **Key Emulation:** Uses key emulation to block and simulate key presses.

## Usage

### Installation

1. Download the **LeagueOfQuests_Installer.exe** from the repository.
2. Run the installer and follow the on-screen instructions to install the application.

### How to Use

1. Open the League of Quests application.
2. Adjust the settings according to your preferences.
3. Click on the "Start" button to begin (waits until the game starts).
4. Launch League of Legends and join a non-competitive game mode.
5. In-game, you will receive quests and restrictions according to your settings.
6. During gameplay, you can relocate the quest display by left-clicking and dragging it.
7. While the program is running, a new window will appear where you can stop and restart the program.

### Important Notes

- **Borderless Window Mode:** The window mode of League of Legends must be set to borderless so that the UI from League of Quests can be shown.
- **ARAM Mode:** The tool works in ARAM mode, but it is not optimized for this mode and may not provide the best experience.
- **Compatibility:** Please note that the program is not compatible with the champion Aphelios due to his unique mechanics.
- **Non-Competitive Use:** This tool should only be used in non-competitive modes to maintain fair play.

### System Requirements

- Operating System: Windows 10 or later
- Storage: 130 MB available space
